個人情報の取り扱いについて

このアプリに入力した文章は、あなたのブラウザの中だけで処理されます。サーバーやデータベースには一切送信・保存されません。
入力内容はどこにも記録されません
ページを閉じたり更新したりすると、内容は完全に消えます
運営者を含め、誰もあなたが書いた内容を見ることはできません
ログイン不要、個人を特定する情報の入力も不要です
安心して、思っていることをそのまま書いてみてください。

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

✨️On Privacy & Your Data
The text you write in this app is processed entirely inside your own browser. Nothing is sent to or stored on any server or database.
Nothing you type is ever recorded anywhere
Closing or refreshing the page erases it completely
No one — including the app's creator — can ever see what you wrote
No login required, no personal information needed
You can write exactly what you're feeling, freely and safely.
Built with React/TypeScript (Vite), deployed via GitHub and Vercel — a purely front-end app with no backend server.
If the actual build for this specific app differs (e.g. it's a single-file HTML/p5.js app rather than React), let me know and I'll adjust that last line to match exactly.
